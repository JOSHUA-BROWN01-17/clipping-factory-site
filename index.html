Clipping Factory

This app uses YouTube API Services

Clipping Factory is a small, privately operated tool that helps one owner run their own short-form comedy channels. It turns long-form videos that the owner is authorised to clip (through paid clipping campaigns) into short vertical clips, and uploads clips that the owner has personally approved to the owner's own YouTube channels as Shorts.

How it uses YouTube

  • The owner signs in with Google's official OAuth sign-in and grants access to their own channels. The app never asks for, sees or stores a password.
  • It uses only two YouTube Data API operations: videos.insert (upload a clip the owner approved) and channels.list with mine=true (confirm which channel was signed in).
  • Every upload is approved by a person first. Uploads are limited to a few per channel per day.
  • It does not read, edit or delete existing videos, comments or other users' data, and it never deletes anything.

Channels

The app uploads only to the owner's own channels: @podpunchlinesdaily and @standupsnippetsdaily. It is not offered to other users.
